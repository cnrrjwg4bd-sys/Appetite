# Appetite
## Client Problem
Staff and teachers have a 20-minute lunch break and need to order ahead from local spots or school lunch so they can collect and eat on time.

## Confirmed Requirements
- App Name: Appetite
- Color Theme: Dark blue and white
- Vendors: Burger King, Sun's Pizzeria, School Lunch, and nearby local options
- Separate menu for each food option
- Shopping cart, discount/bonus code, card payment, and pickup time scheduler
